# AI 雙證照模擬測驗 V0.2

適用範圍：

- iPAS AI 應用規劃師初級：科目一「人工智慧基礎概論」
- iPAS AI 應用規劃師初級：科目二「生成式 AI 應用與規劃」
- 資策會「生成式 AI 能力認證」

## 本版功能

- 三個考區
- 10 題、20 題或本版全部題目
- 章節篩選
- 依正式考試節奏計時
- 題號導覽、未作答狀態與題目標記
- 自動計分與章節正確率
- 完整答案與解析
- 錯題重做
- 瀏覽器本機保存最近 30 次成績
- 手機與桌面自適應

## 重要聲明

本題庫是依官方公開考試範圍編寫的原創練習題，不是官方試題，也沒有重製付費題庫。
V0.1 已完成基本答案、索引與程式邏輯檢查，尚待 Claude 第二輪獨立稽核。

## 本機使用

將 ZIP 解壓縮後，直接以 Chrome 或 Edge 開啟 `index.html`，不需要安裝任何套件。

## GitHub Pages 部署

1. 建立新的 GitHub Repository。
2. 將四個檔案上傳至 Repository 根目錄。
3. 到 Settings → Pages。
4. Source 選擇 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/ (root)`。
6. 儲存後等待 GitHub 產生網址。
