## 題庫品質驗證

每個考區 20 題的正解位置：

- A：5 題
- B：5 題
- C：5 題
- D：5 題

全題庫共 60 題：

- 正解為「唯一最長選項」：0 題
- 正解與其他選項並列最長：10 題
- 正解不是最長選項：50 題

- 三個考區

- 正式考試節奏計時
- 選項順序打亂
- 題號導覽與題目標記
- 自動計分與章節正確率
- 完整答案與解析
- 錯題重做

- 匯出歷史紀錄 JSON
- 手機與桌面自適應
